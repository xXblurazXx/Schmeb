About the Library

This collection is a fan-made effort to preserve classic web gaming in one place.

Controls: Flash games use their own input systems through Ruffle. Press Esc to close the player.

Performance: The emulator pauses automatically when the tab is hidden or the player is scrolled off screen. If a game runs rough, try switching the renderer between Canvas and WebGL — on machines without a real GPU, Canvas is often faster.
